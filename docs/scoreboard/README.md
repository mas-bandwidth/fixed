# Accuracy scoreboard

Measured by `fixed_sweep` against MPFR at 256 bits over the domain pieces in
`sweep/README.md`. Error is in raw units (2^-16). Saturating and documented
out-of-domain results are compared as exact values.

| function | max error (raw) | not correctly rounded | scoreboard |
|---|---|---|---|
| exp2 | 10,416,832,488 | 2,191,712 | [exp2.md](exp2.md) |
| exp2_exact | 1 | 1 | [exp2_exact.md](exp2_exact.md) |
| log2 | 0 | 0 | [log2.md](log2.md) |
| pow | 253,430,483,816,120 | 494,397 | [pow.md](pow.md) |
| atan | 2 | 180,941 | [atan.md](atan.md) |
| sqrt | 1 | 13,501,601 | [sqrt.md](sqrt.md) |

The large exp2 and pow maxima are the saturation boundary: a value just below the top of
the Q48.16 range against `INT64_MAX`, not an approximation error in the interior.

Rows are regenerated by the sweep itself, one function at a time:

```
cmake -S . -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo -DFIX_BUILD_SWEEPS=ON
cmake --build build --parallel 3
./build/fixed_sweep --fn <name> --threads 3
```

The nightly workflow runs every descriptor (`.github/workflows/sweep-nightly.yml`); the
per-function markdown is committed from those runs.
