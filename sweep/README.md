# The MPFR sweep

`fixed_sweep` measures every math function against MPFR at 256 bits over every representable
input where that is feasible, writes a committed scoreboard under `docs/scoreboard/`, and
writes every input that is not correctly rounded to `build/sweep/<name>.notcr` (never
committed). It is built only on a Linux bench with MPFR and GMP, and runs in the nightly
workflow; it gates nothing.

## Build and run

```
cmake -S . -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo -DFIX_BUILD_SWEEPS=ON
cmake --build build --parallel 3
./build/fixed_sweep --fn exp2_exact --threads 3
ctest --test-dir build -L slow --output-on-failure
```

Configure without `FIX_BUILD_SWEEPS` builds no sweep target. If MPFR or GMP is missing the
configure message names the missing library and skips the sweep; it is never an error.
`fixed_sweep_emulated` is the same sweep linked against the emulated 128-bit library.

Options: `--fn <name>` runs one descriptor, `--threads <n>` splits each piece into contiguous
input blocks (outputs are merged in input order, so the hash is thread-count independent),
and `--emit-points <file>` writes a C header of raw inputs and correctly rounded raw outputs:
every libfixmath edge, 4096 xorshift64 draws with seed `0x9E3779B97F4A7C15`, and the 256 worst
inputs of the sweep. That header feeds a fast test with no MPFR.

## Output

One line per piece:

```
sweep fn=<name> piece=[<lo>,<hi>) mode=<exhaustive|sampled> inputs=<n> maxerr=<m> notcr=<count> worst=<raw> hash=<fnv64 of every output>
```

The reference is RN(f(raw * 2^-16) * 2^16) to nearest-even in MPFR at 256 bits; the error is
`|result - reference|` in raw units (2^-16). Saturation and documented out-of-domain results
are compared as exact values. Seeded draws use xorshift64 with seed
`0x9E3779B97F4A7C15`, never the clock.

## Domain pieces

| function | piece | inputs |
|---|---|---|
| exp | every raw over `[ln 2^-17, ln 2^47)` | about 2.9M |
| exp2 | every raw over `[-17, 47)` | 4,194,304 |
| sinh, cosh | every raw with `|x|` below `asinh(2^47)` | about 4.4M |
| tanh | every raw with `|x|` below the point where RN(tanh) reaches 1 | about 0.8M |
| asin, acos | every raw in `[-1, 1]` | 131,073 |
| atan | every raw with `|raw|` at most `2^17`, plus `2^20` seeded raws above | 262,145 + 1,048,576 |
| log2 | every raw in `[1, 2^20]`, plus `2^18` seeded raws per binade above | 1,048,577 + 11.5M |
| sqrt | every raw in `[0, 2^24]`, plus `2^18` seeded raws per binade above | 16,777,217 + 10.2M |
| pow | the glibc pow points, plus `2^20` seeded pairs base `(0,16]`, exponent `[-8,8]` | 1,048,592 |

Every descriptor also runs the libfixmath edge list from `sweep/data/libfixmath_edges.h`.

## How a function joins

Add one `sweep/fns/<name>.c` defining `const sweep_fn sweep_fn_<name>`: a name, arity, the
fixed function as a call on raw inputs, the MPFR reference, the domain pieces and the edge
list. CMake globs `sweep/fns/*.c`, generates the registry at configure time and adds CTest
`sweep_<name>` with label `slow`. Nothing else is edited, and the function's scoreboard is
regenerated by its run.

It runs on Linux benches and nightly only, never in the default CTest tier.
